- Trong tool merge, split pdf, image2pdf, phần tạo bookmark, bổ sung thêm các preset bookmark đi. Ví dụ như tool merge pdf thì preset là mỗi file làm một bookmark tổng, trong mỗi bookmark tổng đó là bookmark con của file đó.
- Trong tool merge pdf, khi đang mode xem file pdf, khi double click thì hiện lên preview pdf, cái đó oke, nhưng khi tôi nhán chuột phải và xem phóng to thì thay vì hiện lên pdf preview thì lại hiện lên page/image của page đầu tiên của file. Fix cái đó giúp tôi đi.
- Hiện tại trong các component có thể scroll được như là bookmark tree thì khi scroll đến cuối thì việc scroll tiếp sẽ làm scroll luôn cả toàn bộ page luôn, xóa cái đó đi, khi đang hover lên cái nào thì chỉ scroll cái đo thôi, muốn scroll bên ngoài thi hover chuột ra bên ngoài
- Trong bookmark tree hỗ trợ thêm shortcut ctrl + c, ctrl + x, ctrl + v đi. Cái khung title của mỗi section hiện tai mặc định là input, bỏ cái đó đi, chỉ khi double click vào khung title thì có thể thay đổi title của bookmark.Còn page number thì giữa nguyên. Section của bookmark khi hover trên cả title thì có thể kéo thả thay đổi vị trí luôn thay vì chỉ hover lên  icon lưới kéo thả. Đem trở lại việc Bổ sung thêm cả đường phân cấp trong bookmark tree luôn đi. 
- Trong tool image2pdf, merge pdf, khi tôi click chuột phải vào trong page/image đã có bookmark thì bổ sung thêm cái button remove bookmark đi. Có thể gắn bookmark cho page đầu tiên của file pdf khi đang trong view file pdf mode.
- Trong tool merge pdf, bổ sung thêm undo trong khung hiện thị các page/file đi
- Trong tool merge pdf, bookmark tree, bổ sung thêm việc có thể thêm section mới ở đầu Bookmarks tree hoặc cuối Bookmarks tree tùy user config.
