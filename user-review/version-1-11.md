- Hiện tại trong tool image2pdf thì khi ấn show bookmark thì sẽ có một cái khung bookmark hiện ra và đẩy cả cái button show bookmark sang một bên luôn. Còn trong tool pdf merge and split thì khi ấn show bookmark thì khung bookmark chỉ đẩy list các page sang một bên thôi, còn button bookmark cùng cái khung chứa nó thì vẫn nằm ở trên không đổi. Tôi muốn bạn chỉnh giao diện của việc đóng mở bookmark của tool image2pdf như là tool pdf merge and split
- Trong các tool image2pdf, pdf merge and split, hiện tại đang có thể thay đổi pages (images)/ row, bổ sung thêm 8 pages (images)/row đi
- Hiện tại tool image2pdf thì khung output file name được đặt ở trên cùng nhưng tool pdf merge and split lại đặt cái khung output file name ở giữa khiến cho UI không thống nhất. Hãy thay đổi vị trí khung output file name của tool pdf merge and split lên trên cùng đi (chỉ nằm dưới swtich merge/order và split pdf).
- Trong tool pdf merge and split, khi tiến hành import nhiều file pdf thì bổ sung thêm loading ở trong khung file/folder selection đi (như là tool manga packager)
- Trong tool pdf merge and, phần split file pdf, khi tôi import file pdf tầm trên 300 page thì giao diện height của mỗi page thành vài pixel (tức là tôi khong thể thấy được page đó là page nào cả). 
- Trong tool pdf merge and, phần split file pdf, bổ sung thêm pages/row cho phần pdf source page đi
- Trong tool pdf merge and, phần split file pdf, phần khung Output PDF Sections, logic và giao diện drag & drop làm tương tự như là việc sắp xếp page của tool image2pdf đi. Trong khung Output PDF Sections, khi double click vào trong các page thì sẽ mở ra modal hiển page đó đi.
- Trong tool pdf merge and, phần split file pdf, giao điện resize width của hai khung Source PDF Pages và Output PDF Sections, thay đổi cái cột nhỏ ở giữa để resize, thay đổi cho nó tương tự như là resize height đi
- Trong tool pdf merge and, phần split file pdf, trong phần Output PDF Sections, hiện tại chỉ có resize cả khung thôi, bổ sung thêm việc resize mỗi section trong khung đó nữa. 
- Trong tool PDF Merge & Split, phần split pdf, hiện tại thì split chỉ được chọn 1 file pdf thôi, thay đôi là nó có thể chọn nhiều hơn 1 file pdf để split.
- Trong tool batch rename, khi tôi tiến hành rename thành công thì toast hiện lên lại thông báo là export thành công, thay đổi lại thành rename thành công đi
- Trong too image2pdf và PDF Merge & Split, khi tôi double click và trong nút xoay image/pdf thì tôi chỉ muốn xoay ảnh 90 độ thôi nhưng bên cạnh xoay 90 độ thì nó còn mở cả modal phóng to page/ảnh ra luôn, tôi chỉ muốn khi double click vào trong image/page thì nó mới mở modal ra thôi.
- Trong tool PDF Merge & Split, việc load thumbnail của các pages có lỗi. Các pages đầu thì có thể load bình thường nhưng khi tôi scroll về các pages ở dưới thì thumbnail không còn load được nữa, fix lỗi đó đi.
