- Hiện tại trong tool image2pdf, khi tôi xóa danh sách cách ảnh ra thì RAM chưa được giải phóng. Tôi kỳ vọng RAM sẽ được giải phóng khi xóa ảnh ra khỏi danh sách
- Hiện tại thì khi tôi tiến hành import một file nào đó vào (vd ở tool pdf merge & split, document to pdf,), thì tuy là vẫn import dược như thường, không có vấn đề gì cả, nhưng mà phần UX cần phải làm nổi bật hơn là file đã được import vào thành công rồi, như là hiện cái toast nhỏ cỡ 1s báo là đã import xong rôi hoặc là tô màu nền nhẹ cho cái đường dẫn của file đã import vào.
- Trong tool pdf merge and split, phần split pdf, tôi muốn khi tôi double click vào page pdf trong section source pdf page thì sẽ mở modal và phóng to cái page pdf đó ra.
- Trong tool pdf merge and split, phần split pdf, cỡ chữ của section source pdf page hiện tại quá nhỏ, tôi muốn nó to hơn một tý (có thể chỉ nhỏ hơn cỡ chữ hiện tại của app một bậc)
- Trong tool pdf merge and split, phần merge/reorder pdf, có thể kéo thả thay đổi, sắp xếp vị trí của các page với nhau. Bỏ đi cái mũi tên sắp xếp trên mỗi page đi.
- Trong tool pdf merge and split, phần merge/reorder pdf, double click vào page sẽ hiện lên cai modal phóng to page đó ra.
- Trong tool pdf merge and split, phần merge/reorder pdf, bổ sung thêm phần có thẻ edit bookmark như là tool image to pdf. Bổ sung thêm việc có thể thay đổi số lượng page trên mỗi row như là too iamge2pdf.
- Trong tool pdf merge and split, phần merge/reorder pdf, có thể xóa một file pdf trong tổng số pdf được import vào, và khi bị xóa đi thì các page của file pdf đó sẽ bị xóa theo (nhớ hiện modal cảnh báo người dùng các page của file đó sẽ bị xóa theo luôn)
- Bổ sung thêm setting mức độ chi tiết của log trong phần activity logs. Có 3 mức độ tối giản (là log như hiện tại), bình thường (chi tiết hơn tý, vd như là trong tool manga packager khi mà nén của một thư viện thì chỉ cần hiện đến mức ra chapter nào đang được nén thôi), chi tiết (hiện chi tiết cả việc đang xử lý ảnh, page, nào nữa)
- Trong phần activity logs, hiện tại đang logs sơ sài quá, bổ sung thêm log chi tiết vào đi (vd như là khi dùng tool image2pdf thì khi export ra thì hiện là đang xử lý ảnh  nào luôn.)
- Trong các tool có export file (pdf, zip,...), bổ sung thêm phần cho phép user cấu hình tên của file khi xuất (cần kiểm tra cái tên đó có tồn tại ngay tại vị trí export không)
- Bổ sung thêm setting default export directory. Nếu như user không cấu hình hoặc là cấu hình ở chỗ mà không có quyền ghi vào thì cảnh báo user. (cần kiểm tra sau khi user ấn lưu cấu hình). Nếu như user không cấu hình (để trống) thì làm như hiện tại, mở file manager ra cho user chọn chỗ lưu. Nếu như user cấu hình rồi thì cứ export ra folder đó
