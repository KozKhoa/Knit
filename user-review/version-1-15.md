- Trong tool pdf merge and split, phần merge pdf, có 2 mode sắp xếp:mode 1 là sắp xếp từng  page như hiện tại, mode 2 là sắp xếp các file pdf (tức là chỉ cần merge các file pdf vơi nhau, không cần thay đổi chi tiết các page của file với nhau). Nếu như đang trong mode 2 thì có thể chuyển sang mode 1 và giữ nguyên thứ tự sắp xêp của các file với nhau. Nếu đang trong mode 1 mà các page trong file chưa được hoán với nhau thì có thể chuyển sang mode 2 và vẫn giữ nguyên thứ tự các page đang có ở mode 1, nếu như đã hoán với nhau (vd như page của file 1 nằm giữa các page của file 2,...) thì hiện lên modal thông báo là toàn bộ thay đổi của mode 1 sẽ bị reset do các page bị hoán với nhau.
